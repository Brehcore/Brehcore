### 💻 Sobre Mim

Sou desenvolvedora de software com foco no ecossistema **Java e Spring Boot**, atuando em todo o ciclo de vida do software (**SDLC**) — desde o levantamento de requisitos de negócio e modelagem relacional até a conteinerização, deploy e sustentação de ambientes em produção.

Minha base analítica consolidou-se em automações e resolução de gargalos operacionais no setor corporativo (SST, RH e Financeiro), transformando regras complexas em soluções digitais resilientes. Hoje mantenho plataformas SaaS de propriedade própria em produção contínua, priorizando código limpo, arquitetura desacoplada e infraestrutura eficiente sob restrição de recursos.

### 🧰 Stack & Ferramentas

* **Back-end:** Java 17+, Spring Boot 3+, Spring Security (JWT / RBAC), Spring Data JPA, Spring WebSocket, Spring Cloud, SpringDoc OpenAPI (Swagger), Flyway, Jakarta EE.
* **Qualidade & Testes:** JUnit 5, Mockito (testes unitários e mocks de serviços/controllers).
* **Bancos de Dados:** PostgreSQL, MySQL (modelagem relacional, esquemas de migração, prevenção de problemas de N+1 com `EntityGraph` e `Join Fetch`).
* **DevOps & Cloud:** Docker, Docker Compose, Docker Swarm, Linux/Bash, SSH, Oracle Cloud (OCI), VPS Linux (otimização de instâncias com Swap).
* **Front-end & Contratos:** Angular, TypeScript, integração orientada a contratos gerados via OpenAPI Types.
